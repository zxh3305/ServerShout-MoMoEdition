# 📣 ServerShout MoMoEdition

[English](./README.md) | 简体中文

ServerShout 是一款适用于 BungeeCord/Velocity/Bukkit 的跨服喊话与邀请插件。具备高性能和高度自定义的特点，兼容 PlaceholderAPI 和 LuckPerms 插件。支持多种消息格式，允许自定义频道和指令，以及消息屏蔽等功能。

本版本提供用于文本处理的额外事件，允许其他插件在ServerShout向玩家发送消息之前检测或替换字符。

了解更多详细信息，请访问我们的[帖子](https://www.minebbs.com/resources/servershout-momoedition.17346/)。
